# HTML & CSS Course Assignment

This project is my first course assignment for the HTML & CSS module, where the goal was to turn a previously created design from Design 1 into a fully functioning, responsive multi-page website.

The assignment required demonstrating practical understanding of HTML, CSS, responsive design, accessibility and project structure.

# 🚀 Project Goal

The main objective of this assignment was to put into practice all foundational skills learned during the course by:

- Building a responsive multi-page website
- Following semantic, valid and accessible HTML
- Structuring clean and reusable CSS
- Reproducing the design from the previous course assignment
- Applying responsive layouts using Flexbox and CSS Grid
- Ensuring good UX on all screen sizes without using CSS frameworks
